Forensics Suite 2.1

A standalone, local-processing archaeological image-analysis application. No uploads to a server, external scripts, or network services are required by this file. Camera access requires browser permission and a secure context (HTTPS or localhost).

Original, working base, and derived output

The uploaded original file is retained unchanged for the current session. Save Original downloads those original bytes. Restore Original resets the working base. The blue arrow commits the current processed result as a new working base without changing the session original. Reset View resets the current module, not the original source. Loading a new image starts a new image session. Nothing persists after closing or reloading unless you export it.

Resolution and exports

Full source is the default. Optional limits reduce processing dimensions explicitly. PNG exports use processing dimensions, never a cropped or zoomed screen canvas. Thumbnail grids alone use smaller previews. Very large images can exceed browser memory; choose a limit if necessary. Brightness-gradient and smoothing operations depend on pixel scale. Export Log records dimensions, settings, transform coefficients, operations, source filename, and a SHA-256 source hash when supported. The log is a provenance aid, not a certified chain of custody or an importable project file.

Color enhancement

DP computes covariance, sorted eigenvectors, and regularized decorrelation. YUV uses luminance/chroma coordinates; RGB uses native channels; Chroma uses YUV with deliberately reduced luminance gain and increased chroma gain; Opponent uses a reversible brightness/red-difference/blue-difference transform, not CIELAB. Component suppression attenuates the largest-variance principal component, not an independent component and not physical depth. Optional smoothing never replaces the original. Area mode fits and applies the transform inside a selected rectangle. Wand mode samples unprocessed working pixels, fits matching colors, and makes unmatched pixels transparent. Compare shows the current unenhanced working base.

TopoLight

The movable light shades brightness-derived pseudo-normals. It is an illustrative relief effect, not 3D reconstruction, measured normals, RTI, subsurface imaging, or depth. Color changes and shadows can appear as relief. The edge switch displays smoothed Sobel intensity edges.

RetroGrid 16

All views derive from the same three RGB channels. They are not 16 spectral measurements. Floating-point channel values remain separate from display mapping. Display ranges are fixed: RGB/luminance/value 0–255; hue 0–360 degrees; saturation 0–1; opponent differences −255–255; chroma centered on 128; ratios 0–3; Sobel magnitude mapped with a fixed scale. Ratios above 3 clip in the display only. Near-zero denominators and low-saturation hue require caution. Exports are visualization PNGs, not calibrated radiometric data.

Live color view and edge video

Live color statistics are locked to the central half-frame when a preset is selected. Refresh Color Reference deliberately refits them. The camera capture retains the full unfiltered frame as the session original. The video module computes Sobel edges with optional smoothing, pre-contrast, sensitivity, threshold and inversion; it does not perform X-ray imaging or temporal detection. Video export records browser playback in real time, is silent, and can drop frames on slow devices or in a background tab. Keep this tab visible. Export depends on browser MediaRecorder and canvas capture support.

Interpretation

Enhanced colors, relief and edges are visual hypotheses, not chemical identification, buried-feature confirmation, or independent corroboration. Always compare with the original and document processing settings.

Synthetic UV viewer

This is deterministic false-color enhancement of visible-image pixels, not measured ultraviolet fluorescence, spectroscopy, mineral identification, or recovered depth. No AI is used. Color Glow expands opponent-color differences and local detail; Reference Glow suppresses similarity to a patch sampled from the unprocessed working base. Trace Glow overlays absolute multiscale luminance detail, not verified incisions. The blue–cyan–amber palette has no chemical meaning.

Open Synthetic UV on Home. Adjust Sensitivity and Background Darkness, then rotate Color Axis. Reference Glow: choose Sample surface and tap a patch to suppress; drag and pinch still navigate. Detail Size controls two smoothing scales relative to image size; enable Trace Glow for detail highlighting. Original Blend 100% returns the unchanged processing image. Hold Original shows the unprocessed working base at the exact same zoom/pan; it does not change settings or reset the view. There is no split view. Fit resets navigation only. Sweep rotates Color Axis; Hold freezes the last visible enhanced result. Editing a control, holding Original, leaving the module or hiding the tab stops Sweep.

The interactive preview is limited to 900 pixels on its long edge (700 on narrow screens). Save PNG recomputes the complete image at the Home processing resolution, not a zoomed screen crop; smaller preview scales can look slightly different. PNG settings downloads a separate JSON describing the last successfully saved PNG, including its frozen parameters, reference patch, dimensions, source metadata and processing description. Changing controls afterward does not change that PNG settings record. No reference patch is painted into the exported image. The session original remains unchanged.
